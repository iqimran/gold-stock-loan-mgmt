# 13 — Definition of Done

A feature is Done only if:
- requirement is documented
- backend validation exists
- authorization exists
- database changes are migrated safely
- UI is responsive
- loading/error/empty states exist
- tests exist for business-critical behavior
- financial mutations are transactional
- audit trail exists where required
- reports use authoritative data
- no unrelated refactor is included
- lint/type/test checks pass
- task documentation reflects final behavior
